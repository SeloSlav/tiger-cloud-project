# Frostline logo

Asset: `public/frostline-logo.png`.

Used in the dashboard header. The relative image URL resolves under both the local root and the GitHub Pages repository prefix.

Created with the built-in image-generation tool. PNG with an alpha channel; transparent background verified from the saved file. Intended for the dark Frostline interface. This is a raster brand asset; an editable vector master is not included.

## Browser favicon

`public/favicon.svg` is a separate, editable small-size emblem using the same icy thermometer, frost branches and salmon sushi themes. Its dark rounded tile keeps the pale strokes legible in light and dark browser tabs. It omits the wordmark and fine detail for small sizes.

The SVG is the scalable browser icon; `public/favicon-32.png` provides a 32-pixel PNG fallback, and `public/favicon.ico` contains 16-, 32- and 48-pixel images. Raster fallbacks are rendered from the SVG. Metadata uses the correct GitHub Pages prefix and a versioned URL to refresh cached icons.

## Final generation prompt

Create a professional transparent-background PNG logo for frostline.
A clean horizontal brand lockup: on the left one original geometric emblem cleverly combining a sushi maki roll, an icy snowflake, and a temperature-monitoring thermometer; on the right the exact lowercase word "frostline" in a bold carefully kerned geometric sans serif.
The sushi circle is the thermometer bulb, with dark teal nori, a smooth white rice ring, and a small striped salmon-orange center. An icy cyan thermometer stem extends upward into simple angular frost branches. Confident minimal shapes and balanced negative space. The lettering is pale icy mint to be readable on a dark interface.
Flat colors and precise smooth vector-like outlines throughout. No texture or decorative particles. Entire logo fully visible with modest transparent margins, in a wide horizontal image.
IMPORTANT: deliver an actual PNG cutout with a completely transparent background. The outer background and holes in the letters must be transparent. Only the logo itself should be visible.
